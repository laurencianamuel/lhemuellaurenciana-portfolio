# Portfolio Website

A personal portfolio website built with React, Vite, TypeScript, Tailwind CSS, and shadcn-ui.

## Project setup

1. Clone the repository
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```

## Technologies used

- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn-ui

## Scripts

```sh
npm run dev
npm run build
npm run preview
```

## Deployment

You can deploy this project to any static hosting platform such as Vercel, Netlify, or GitHub Pages.
